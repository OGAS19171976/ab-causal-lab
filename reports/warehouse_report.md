### 5. 负对照诊断 —— 为什么必须做前置协变量校正
exp_rec_emb 的真实效应是 0（负对照）。如果 post-only 分析给出显著结论，
那一定是这一次分流的协变量失衡造成的假象。

协变量失衡诊断: exp_rec_emb  (n=11,913)
  corr(pre, post) = 0.7935
    方差缩减 = rho^2 = 0.6296   （残余方差 1-rho^2 = 0.3704，标准误降幅 0.3914，等效样本量 x2.70）
  这一次实现的分流:
    前置组间差   = -6.4277
    后置组间差   = -8.3033   <- 未经校正的结论
    校正后差距   = -3.1460   （偏置被消掉 62.1%）
  重新分流 1000 次得到的分布:
    theta = 0.8023（合并样本估计，线上实际使用的值）
    theta（参考） = 0.8257 —— 从差距分布反推，比合并样本估计更嘈杂，且系统性略低
      （差距分布的相关系数比个体级相关略小，属于二阶效应）
    校正前 sd = 3.3994  ->  校正后 sd = 2.1096
    实测方差缩减 = 0.6149  (理论 rho^2 = 0.6296)
对照看有真实效应的实验：

协变量失衡诊断: exp_rank_v2  (n=16,033)
  corr(pre, post) = 0.7952
    方差缩减 = rho^2 = 0.6323   （残余方差 1-rho^2 = 0.3677，标准误降幅 0.3936，等效样本量 x2.72）
  这一次实现的分流:
    前置组间差   = +6.2033
    后置组间差   = +25.8458   <- 未经校正的结论
    校正后差距   = +20.8718   （偏置被消掉 19.2%）
  重新分流 1000 次得到的分布:
    theta = 0.8018（合并样本估计，线上实际使用的值）
    theta（参考） = 0.8144 —— 从差距分布反推，比合并样本估计更嘈杂，且系统性略低

结论：
  * 负对照实验的 post 差距 -8.3033 里，约 62% 被 CUPED 扣掉
  * 方差缩减 = rho^2 = 0.6296（残余方差 1-rho^2 = 0.3704，标准误降幅 0.3914，等效样本量 x2.70）
    实测方差缩减 0.6149，与理论吻合
  * 有真实效应的 exp_rank_v2（真实日效应 +2.00）：
      校正前 +25.8458 -> 校正后 +20.8718，更接近真值
  * -> M1 将把这个诊断正式实现为 CUPED，并作为默认分析口径

### 簇级 CUPED：整簇随机化 + 前置指标（本轮打开的一条口径）
  这条口径原先被**创建时就拒绝**，理由写的是「数据源没有簇级前置指标」。
  实测那是个**过时假设**：05 路 DWS 一直落着簇级的 pre/cross 列，
  pre_sum ≈ 4.4e6。现在按声明走，真拿不到前置指标时由分析层报错。

  estimator=post_only  效应 +20.4636  SE 2.8720  分析单元数 60（簇）
  estimator=cuped      效应 +19.3969  SE 1.7107  分析单元数 60（簇）
    ρ=0.6224  方差缩减 38.74%  标准误降 21.73%

  两条口径的**观测单位都是簇**（自由度 = 簇数 − 2），CUPED 只是把
  每簇的 (前置均值, 后置均值) 当成一对观测再做回归调整 ——
  与单元级 CUPED 是同一份实现（``cuped_estimate``）。
  边界：这一轮**没有**量簇级 CUPED 的 A/A 校准（数仓只有一份实现，
  换不了 salt），所以只报「与 post-only 相比方差确实降了」，
  不声称名义覆盖率 —— 那句话要等一个能重复抽样的路径才敢写。
