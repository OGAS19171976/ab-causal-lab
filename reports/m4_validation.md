# M4 验证报告

```text
==========================================================================

DML · 因果森林 · Uplift 与 Qini
==========================================================================

M4 的验证台比前三个阶段难：DML 的 theta 有真值可比，
但 CATE 没有唯一正确答案 —— 答案取决于 DGP 的函数形式。
所以下面**四种形式各跑一遍**，「没有单一赢家」本身就是结论。

### 1. DML 消掉 naive plug-in 的偏置（每个样本量 15 次仿真）
DML vs naive plug-in（15 次仿真/样本量）
  真 theta = +1.000（constant CATE 下的 ATE）
  n= 1000: naive 偏置 +0.1650 覆盖率 0.60 | DML 偏置 +0.0694 覆盖率 1.00 | 不交叉拟合 +0.0490
  n= 4000: naive 偏置 +0.1862 覆盖率 0.13 | DML 偏置 +0.0142 覆盖率 0.93 | 不交叉拟合 -0.0156
  -> naive 的偏置**不随 n 消失**，覆盖率从 60% 崩到 13%：更多数据只会让有偏的区间更自信地错。
  -> DML 的偏置随 n 收缩（+0.069 -> +0.014），覆盖率守在 93%。
  -> 但注意 n=1000 那一行：nuisance 太弱时 **DML 自己也偏** 它的渐近保证要求 nuisance 收敛快于 n^{-1/4}，小样本 + 弱学习器不满足。

### 2. 因果森林 vs 常数基线（n=3000，四种 CATE 形式）
因果森林 vs 常数基线（n=3000，四种 CATE 形式各一遍）
  注意：这是**留出集**上的 MSE。常数基线 = 对所有人报同一个 ATE。
    constant: MSE 森林   0.6747 vs 常数   0.0000（比值      ∞）  秩相关 +nan  Qini 森林    -0.12 vs 常数   -3.48
      linear: MSE 森林   0.9518 vs 常数   0.8492（比值   1.12）  秩相关 +0.882  Qini 森林   233.96 vs 常数   11.32
   threshold: MSE 森林   0.9068 vs 常数   1.0347（比值   0.88）  秩相关 +0.822  Qini 森林   273.70 vs 常数    2.11
   nonlinear: MSE 森林   1.2669 vs 常数   0.8269（比值   1.53）  秩相关 +0.715  Qini 森林   250.38 vs 常数  -81.74
  -> 弹性模型在至少一种形式下赢过常数基线

### 3. 排序指标与水平指标（n=5000）
排序指标 vs 水平指标（n=5000，nonlinear CATE）
  Qini：样本内 613.66 / 留出 466.37 / 完美 604.83 / 常数 11.83
    样本内高估 +31.6%（把评估样本也拿去拟合，Qini 会虚高）
  MSE：森林 1.0433 vs 常数 0.8948

  排序结论：森林优于常数（Qini 466.4 vs 11.8）
  水平结论：森林劣于常数（MSE 1.043 vs 0.895）
  -> **两个指标给出相反结论**。Qini/AUUC 只衡量排序，完全不衡量水平；
     「我的模型 AUUC 更高」不等于「我的 CATE 估得更准」。

### 3b. CATE 的区间：两条路线的覆盖率（n=1500，5 个场景）
CATE 区间的覆盖率（5 个场景 × n=1500，bootstrap B=25，名义 0.95）
  叶内方差 + 跨树影响函数合成：覆盖率 0.2127，长度 0.7241
  按单元 bootstrap　　：覆盖率 0.3087，长度 1.0364（长度差 30.1%）
  点估计诊断：τ̂ 与真值相关 0.6863，RMSE 0.9894
  真 CATE 的 sd 0.9175 vs τ̂ 的 sd 0.4364；可给区间的单元 77.2%
  → 两条路线的覆盖率都远低于名义值，而**区间长度与真 CATE 的离散度同量级**：所以盖不住的主因是**点估计有偏**。
     （方差本身也曾在跨树上按独立合成而偏小，修法见报告第 8c 节：SE 从真实抽样波动的 0.354 倍抬到 0.702 倍，覆盖率仍上不去 —— 偏差是 SE 的 7.46 倍。）

  验收标准逐条对照（写到报告里，而不是留在脑子里）：
    · 覆盖率 ≈95%（同质 ≥90%）：**不满足** —— 解析 0.2127、bootstrap 0.3087
    · 与 bootstrap 的长度差 ≤30%：**不满足** —— 实测 30.1%
    · 区间长度随 min_leaf 单调收缩：**标准撤回** —— 那是旧口径（只量叶内噪声）的副产品，改成影响函数相加后中位 SE 基本持平；叶子大小换的是偏差不是方差（见 reports/cate_interval_report.md 第 3 节）
    · 明确回答「水平仍不可靠」是否成立：**成立**，且原因已量化
  → 所以第 3 节那句「森林 MSE 反而更差」在加了区间之后依然是结论，
    而现在它多了一个解释：区间盖不住的主因是**点估计有偏**
    （跨树方差本身也曾算错，第 8c 节已修：SE 从真实波动的 0.354 倍到 0.702 倍，
     覆盖率仍上不去 —— 偏差是 SE 的 7.46 倍）。

### 3c. 元学习器对照：S / T / X / R / DR（四种 CATE 形式）
  M4 原先只有 S / T / X 三个元学习器。这一轮补上 **R-learner**（Nie & Wager）
  与 **DR-learner**（Kennedy）：两者都用正交化 + 交叉拟合的 nuisance，
  R-learner 最小化 R-loss（等价于一个加权回归），DR-learner 回归双稳健伪结果。
  线性 τ 时 R-loss 有闭式解；非线性 τ 走「伪结果 + 加权拟合」那条等价路径。

  元学习器对照（n=3000，留出集评估，四种 CATE 形式）

    → 每个形式的最小 MSE 方法（**由数据算出来，不写死**）：
      constant   R(线性, 不交叉拟合)（MSE 0.0312）
      linear     R(线性, 不交叉拟合)（MSE 0.0480）
      threshold  X-learner（MSE 0.1923）
      nonlinear  X-learner（MSE 0.3384）
    → **没有单一赢家**：2 个方法各赢至少一种形式（R(线性, 不交叉拟合)、X-learner）。
      这正是本仓库从 M4 起的那条结论 —— 换 DGP 就换赢家，所以「我的模型更好」必须带上「在哪种数据上」。

  三条要一起读的东西：
    · **同基学习器下 R 不差于 T**（四个形式，5% 容差）：True；
    · **没有单一赢家**：每个形式的最小 MSE 方法不同 —— 这是 M4 的老结论；
    · **交叉拟合在 MSE 上不赚**：True（不交叉拟合反而更低）。
      原因是样本内过拟合把 Ỹ 一起缩小、τ̂ 被收缩向 0，相当于正则化；
      交叉拟合买到的是**推断的有效性**（DML 那节量的无偏性与覆盖率），
      不是这个口径上的 MSE。这一条也是**被实测改写过的判据**：
      第一版的对照顺手把不交叉拟合那一支的 ê 换成了常数边际处置率，
      等于一次改了两个变量 —— 对照实验只许改一个。
```
